# Career Sniper 🎯

**KI-gestützter Job-Agent** – Sucht Jobs aus 8 Quellen (inkl. LinkedIn, Indeed, Google Jobs), analysiert Unternehmen und schreibt deine Bewerbung automatisch.

---

## Setup (1 Schritt)

```bash
./start.sh
```

Das war's. Die App öffnet sich automatisch unter **http://localhost:3000**.

> **Voraussetzung:** [Node.js 18+](https://nodejs.org) und [Python 3](https://python.org) müssen installiert sein.

---

## Was kannst du tun?

| Feature | Beschreibung |
|---------|-------------|
| **Jobs suchen** | 8 Quellen gleichzeitig: Bundesagentur, ArbeitNow, Adzuna, Remotive, Jobicy, LinkedIn, Indeed, Google Jobs |
| **Unternehmen analysieren** | KI bewertet jedes Unternehmen: Stimmung, Warnzeichen (0–10), Interview-Fragen, Kultur |
| **Lebenslauf hochladen** | Einmal einfügen – KI passt deinen CV automatisch an jeden Job an |
| **Match-Score** | Wie gut passt ein Job zu deinem Lebenslauf? Badge in Grün/Gelb/Rot (0–100%) |
| **Bewerbungspaket** | KI schreibt Lebenslauf, Anschreiben & E-Mail – fertig zum Versenden |
| **Swipe-Modus** | Tinder-Style: rechts = Vormerken, links = Ablehnen |

---

## Workflow

```
1. "Jobs suchen" → Position + Standort eingeben
2. Lebenslauf einfügen → Match-Scores erscheinen automatisch
3. "Analysieren" → KI bewertet das Unternehmen
4. "Bewerbung erstellen" → Lebenslauf + Anschreiben + E-Mail generiert
```

---

## Erneut starten

```bash
./start.sh
```
